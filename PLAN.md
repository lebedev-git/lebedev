# План: платформа-портфолио Андрея Лебедева

## Что делаем и почему так

Не одностраничная визитка, а **платформа с разделами и лёгкой админкой**, где ты сам
добавляешь проекты через веб-интерфейс. Хостинг — онлайн 24/7 по ссылке.

**Стек: FastAPI + Jinja2 + SQLite (Python).**
Обоснование:
- Python 3.12 у тебя уже стоит и ты на нём работаешь (dashboard.py) — не тащим новую среду (Node под вопросом).
- FastAPI + Jinja2 = серверный рендеринг HTML + REST для админки в одном процессе, один язык.
- SQLite — файл-база `data.db`, ноль настройки, легко бэкапить (просто копия файла). Для портфолио нагрузки нет.
- Легко деплоится на Render/Railway/VPS одной командой (uvicorn), позже — Docker (он у тебя уже освоен).

Отвергнутые варианты: MERN (лишняя JS-среда), Laravel/PHP (нет PHP в окружении),
no-code Webflow/Framer (платно, не покажет твой инженерный уровень, нет полного контроля).

## Разделы (публичная часть)

1. **Главная** — hero + краткая суть + превью последних проектов.
2. **Проекты** — каталог карточек с фильтром по тегам; детальная страница проекта.
3. **Обо мне** — развёрнутая биография, фото, ценности.
4. **Опыт и навыки** — таймлайн работы + стек/компетенции.
5. **Блог** — список заметок + страница статьи.
6. **Контакты** — Telegram (осн.), телефон.

## Админка (лёгкая, /admin)

- Вход по паролю (сессия в cookie; пароль в `.env`, хеш через passlib).
- CRUD проектов: добавить / редактировать / удалить, загрузка обложки (UploadFile).
- CRUD заметок блога (тот же механизм).
- Остальные разделы (Обо мне, Опыт) на старте правим в шаблонах/сиде — упростит запуск.

## Архитектура (структура файлов)

```
Lebedev/
├─ app/
│  ├─ main.py            # FastAPI: маршруты публичные + admin
│  ├─ db.py              # подключение SQLite, инициализация схемы
│  ├─ models.py          # Pydantic-схемы (Project, Post)
│  ├─ auth.py            # логин/сессия/защита admin
│  ├─ seed.py            # первичное наполнение (твои данные из резюме)
│  ├─ templates/         # Jinja2: base, index, projects, project, about, experience, blog, post, admin/*
│  └─ static/
│     ├─ css/styles.css  # тёмная тема из MVP, развитая под многостраничник
│     ├─ js/main.js      # reveal-анимации, фильтр тегов
│     └─ uploads/        # загруженные обложки проектов
├─ data.db               # SQLite (создаётся при первом запуске)
├─ .env                  # ADMIN_PASSWORD, SECRET_KEY
├─ requirements.txt      # fastapi, uvicorn, jinja2, python-multipart, passlib, itsdangerous
└─ README.md             # запуск и деплой
```

## Модель данных

- **project**: id, title, slug, summary, description(markdown/html), cover_image,
  tags(csv), role, year, link, featured(bool), created_at.
- **post**: id, title, slug, excerpt, body, cover_image, published(bool), created_at.
- **profile/experience** на старте — в seed.py/шаблонах (без CRUD).

## Порядок реализации

1. Каркас: requirements, структура папок, db.py + схема, main.py (заглушки маршрутов).
2. Публичные шаблоны + перенос визуала из MVP index.html в base.html/styles.css.
3. Seed данными из резюме (2 места работы, стек, грант 1.2 млн, патент).
4. Админка: auth + CRUD проектов + загрузка обложек.
5. CRUD блога.
6. README: локальный запуск (uvicorn) + инструкция деплоя на Render.
7. Проверка: запустить, пройти по всем разделам, добавить тестовый проект через админку.
