# Портфолио-платформа · Андрей Лебедев

Персональная страница-портфолио с разделами (Проекты, Обо мне, Опыт, Блог) и лёгкой
админкой, где проекты и заметки добавляются через веб-интерфейс.

**Стек:** FastAPI + Jinja2 + SQLite (Python 3.12).

---

## Быстрый старт (локально)

```bash
cd "C:\Disk D\Project\Lebedev"
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env        # затем впиши свой пароль и секрет
uvicorn app.main:app --reload
```

Открой http://127.0.0.1:8000 — публичная часть.
Админка: http://127.0.0.1:8000/admin (пароль из `.env`, поле `ADMIN_PASSWORD`).

При первом запуске автоматически создаётся `data.db` и наполняется данными из резюме
(`app/seed.py`). Повторный запуск данные не перезатирает.

## Структура

```
app/
├─ main.py         # FastAPI: маршруты публичные + admin
├─ config.py       # пути, .env, данные владельца
├─ db.py           # SQLite: схема и запросы
├─ auth.py         # вход в админку (подписанная cookie)
├─ utils.py        # слаги, сохранение загруженных картинок
├─ content.py      # тексты «Обо мне» и «Опыт» (правятся здесь)
├─ seed.py         # первичное наполнение БД
├─ templates/      # Jinja2-шаблоны (+ admin/)
└─ static/         # css, js, uploads/ (загруженные обложки)
data.db            # база (создаётся сама, в git не коммитим)
.env               # пароль и секрет (в git не коммитим)
```

## Что где править

- **Проекты и блог** — через админку `/admin` (add/edit/delete + загрузка обложек).
- **Тексты «Обо мне», «Опыт», навыки, достижения** — в `app/content.py`.
- **Имя, контакты** — в `app/config.py`, словарь `OWNER`.
- **Визуал** — `app/static/css/styles.css`.

## Деплой онлайн 24/7 (Render — бесплатный тариф)

1. Залей проект в приватный/публичный репозиторий GitHub.
2. На https://render.com → New → Web Service → подключи репозиторий.
3. Настройки:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
   - **Environment:** добавь `ADMIN_PASSWORD` и `SECRET_KEY`.
4. Чтобы `data.db` и загруженные картинки не стирались при перезапуске — подключи
   **Persistent Disk** (Render → Disks), примонтируй к папке проекта. На free-тарифе
   диск платный; альтернатива — хостинг с постоянным диском (Railway, VPS) или вынести
   контент в managed-БД (следующий шаг развития).

Альтернатива без диска: контент проектов держать в git (seed-файлы) — тогда правки идут
через код, а не через админку. Обсудим при выборе хостинга.
